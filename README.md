# AI考古学通论 — Quarto starter

A Quarto Book starter with 25 placeholder chapters corresponding to the finalized textbook outline.

## Start
1. Install Quarto: https://quarto.org/docs/get-started/
2. Open this folder in Positron / VS Code, then run `quarto preview` in its terminal.
3. Run `quarto render`; Quarto writes the website to `docs/`.
4. Push the project to `ZCJing2022/AI-Archaeology-Textbook` (create this repository first).
5. GitHub repository Settings → Pages → Deploy from a branch → `main` → `/docs`.

**This starter includes no verified real archaeological datasets.** All chapters are placeholders and must be reviewed.
