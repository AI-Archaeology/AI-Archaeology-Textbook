教师试评分与课堂可行性试测包 V1.1

供教师试验，未实际开展试测。 下列答案全部为虚构学生回应，用于诊断评分规则能否区分不同能力层次；不代表真实学生表现。试测材料不包含原研究的逐行数据。

一、教学材料准备

教师准备：可合法访问的原论文指定小节和图表、两个V1教学模块、四项量规、本页试评分案例；确认至少两名教师独立评分。学生不需要编程、不需要私有CSV。如论文全文或图表无法合法获取，应暂停阅读层正式评分并记录阻碍。

学生提交形式：T3-A一页判断表和关系图；T3-B一段150–250字含原文位置的短评；T11-A一页计算及解释；T11-B一段150–250字含图号与方法说明的短评。允许手写或电子文本。不得要求提交未经批准的原始数据附件。

二、已纳入V1.1必做评价的补充测试题（供教师试评分）

第3章：缺失机制（完全虚构，不是Zhang原始工作簿）

一份模拟陶片表有三行：A记录的直径为0 cm（记录者声称测得零），B记录的直径为NA（没有测量记录），C为非口沿陶片，直径为Not applicable（结构性不适用）。

问题： 这三种值能否互相替换？若要计算可测量口沿的平均直径，需先检查什么？教师判别： 应指出0的测量定义/合理性需要核实，NA不是0，结构性不适用不应作为0或普通已观察值纳入分母。此题只测试数据概念，不指控真实研究含该错误。

第11章：年代区间与分箱（完全虚构）

假设一组12片虚构陶片属于日期范围AD 900–1200的类别。为演示计算，明确采用半开区间［900,1200），假定这一连续300年区间上单位时间均匀分配，且分箱为［900,1000）、［1000,1100）、［1100,1200）。问每箱权重是多少？如改为［900,1050）和［1050,1200），权重又是多少？

教师判别： 第一组为4、4、4；第二组为6、6；总计都为12。要求学生说明这些是模型按假设分配的数量权重，并不意味着真实陶片被独立定年。此处的年份、12片和分箱均为假设演示，不是论文统计结果。教学上必须先给出端点约定，不能让学生猜测时间边界。

三、四份虚构学生作答（诊断材料）

S1｜T3-A（高度达标型）：将216定义为遗址、55为细分类、15为产品类型、896为Assemblage记录、31,729为陶片总数。关系图以Assemblage ID为发现表键，Site ID、Class ID为外键；指出同一Site×Class可有不同Assemblage ID。主张保留7组组合并联系作者核查，拒绝由陶片数直接推断贸易额。预期：四维均可评为3，具体仍由试评分者独立判断。

S2｜T3-A（部分达标型）：五个数字大体记对，但将Site ID×Class ID视为唯一键，认为重复应删除7条，“这样数据更干净”；未讨论调查偏差。预期：单位维可得较高分，键、重复和推论维需明显扣分。

S3｜T11-A（机械计算型）：写出10+10=20、31,729总量不变，但声称“所以论文的年代划分准确”；认为Aoristic与贝叶斯建模相同，因为“都用数学”；没有描述时间箱边界变化。预期：算术分可给部分分数，但方法与推论维不能达标。

S4｜T11-B（有概念但缺来源型）：能说明分配权重不是直接测年，提出保存偏差和分类年代不确定性；却未指明Methodology及Figure 5/8的任何可核对原文位置。预期：方法理解与偏差维可给分，但“原文定位”和图表证据维不得给满分。

重要：这些简短摘要不是足以测试全部四项任务的完整真实学生答案；它们只能用于首次边界评分演练。正式试评分需要教师构造或收集完整、匿名且获准使用的答卷，尤其要补齐T3-B和T11-B的真正阅读引用。

五、检查评分分歧

两位教师先独立评分，再讨论；不可先看预期分数。逐维检查绝对差值超过1分的项目、总分是否跨越8/12达标阈值，以及是否有某项题目要求学生使用根本没有提供的材料。对分歧较大处修订文字锚点后，需用另一组答卷重测；仅有教师讨论，不等于已经测得统计上的评分者间信度。
