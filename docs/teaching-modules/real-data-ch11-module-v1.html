真实研究数据教学模块 V1.1：第11章 年代区间与Aoristic分配

编写组讨论稿，非教材正文定稿。 本模块利用已核验的研究数据结构与年代权重守恒结论进行无代码教学，不转载真实逐行数据。原研究的Aoristic分析是年代不确定性的计算处理方法，不等于贝叶斯年代模型，也不自动属于AI。

1. 从考古问题出发

中国贸易陶瓷在西印度洋遗址的出现如何随时间变化？每类陶瓷可能跨越相当长的生产和流通时期，资料中的一个年代范围不同于单片陶片的精确年代。研究者可用Aoristic方法把给定时间区间的计数分配到多个时间箱，但必须说明分配假设和不确定性。

阅读资料：原论文 · 数据发布页 · 文件级审核记录。

2. 学习成果（5条）

  • C11-O1［核心］ 学生应能解释相对年代、年代区间、时间箱与Aoristic权重的区别，并指出权重并非陶片的直接测年结果。
  • C11-O2［核心］ 学生应能判断一条发现记录的总计数为什么应与各时间箱权重之和相符，解释整体守恒检验的意义。
  • C11-O3［核心］ 学生应能比较区间跨越时间箱时的分配方式，说明分箱边界、区间长度和分配假设可能怎样改变年代图的形状。
  • C11-O4［阅读］ 学生应能区别Aoristic分配、地层与类型学排序、放射性碳测年、贝叶斯年代建模及AI断代的不同证据前提和产出。
  • C11-O5［阅读］ 学生应能核查论文中的年代图或模型表述是否区分计算结果与历史推论，并提出至少两项可能影响解释的考古数据偏差。

4. 用于理解的演示计算（明确虚构，并非本研究记录）

假设有20片教学假想陶片，只知道类别的可能年代跨越两个等长百年时间箱。若采用“均匀分配且两箱等权”的教学假设，可以写成：

假想时间箱 演示分配权重
时间箱A 10.0
时间箱B 10.0
合计 20.0

如果用另一套分箱边界或非均匀时间分配假设，结果可能改变，但仍须核对总权重是否等于20。本演示仅用于说明算术守恒，不代表原作者对任何特定真实记录采用这一分配比例。

需要避免的三种误读

  1. 权重数为小数，不意味着发现了“小数片陶片”。
  2. 某时间箱分配权重较高，不等于每片陶片已独立断为该百年。
  3. 守恒检验通过，不等于保存偏差、调查密度差异、类别断代与研究汇编偏差均已排除。

教师配套： Methodology与Figure 5/8阅读定位及四项任务评分量规。教师必须确认原文可访问，不要将假想20片演示当作论文复现。

5. 必做综合评价（无代码）

材料包： 本页提供的显著标注为虚构的20片示意表、已审核的真实数据结构摘要及原论文。真实原始逐行数据与私有转换文件不提供公开下载。

T11-A：年代模型与分箱判断卡（必做；试用排程建议25–35分钟，非实测）

  1. 解释“陶瓷类型的可能年代范围”“Aoristic权重”“直接测年结果”三者区别。（O1）
  2. 用20片假想材料核对10+10=20，并说明为什么原研究的全部权重应合计31,729。（O2）
  3. 分箱计算与假设敏感性（O3）： 使用下述完全虚构、非Zhang研究记录的情境：12片陶片所属类别的可能年代区间假定为公元[900,1200)，连续300年，采用每年均匀分配；端点约定为左闭右开。先计算三个百年时间箱[900,1000)、[1000,1100)、[1100,1200)的权重，再改为两个150年时间箱[900,1050)、[1050,1200)，计算新权重并核对两种分箱下合计均为12。说明若使用不等长的时间箱为何不能简单等分，以及这种分配不能证明陶片确实出自某个百年。最后指出改变日期起止、分箱边界或均匀分配假设时需要重新检查的条件。
  4. 对比采用类型年代区间的Aoristic分配与加入地层关系、14C测定的贝叶斯年代分析，指出它们需要的证据条件；再判断两者是否应直接叫作AI。（O4）

T11-B：真实论文方法与图表审查（必做［阅读］证据；试用排程建议25–35分钟，非实测）

教师提供并核验可合法节选的原论文方法段与图题，或由学生在有权访问的原始页面阅读。要求写一段150–250字短评：说明作者采用什么年代资料与分配规则，年代图中的数量代表什么，并指出至少两项需核对的偏差或假设（如断代区间、保存及调查偏差、类别之间的可比性）。不得将假想20片分配写成原研究实测结果。（O1、O4、O5）

5分钟短问： “小数权重是不是小数陶片？”“有31,729片陶片是否意味着31,729条独立年代测定？”（复核O1、O2）

7. 何时用、何时不用

当可靠资料仅提供年代区间、研究者需要表达时间覆盖而非伪造精确年份时，Aoristic分配可以作为探索性时间分布表示；但它需要明确区间、分配规则及不确定性。若缺乏可靠类别断代、样本不具代表性、时间箱选择任意或研究问题涉及事件发生的精确年代，则不可将其当作直接证据。传统地层学、排序、独立科技测年及贝叶斯模型提供的是不同类型的比较方案。

8. 版本与发布说明

本模块只提供已审结构汇总和一个明确虚构的算术演示；没有发布真实数据的逐行记录、具体时间箱结果或完整数据附件。待原作者对重复记录与文内异文的说明、公开许可/敏感性审查及编写组批准后，方可制作正式可下载的数据练习。原始研究解释须保持可供学生核对的明确出处。
