真实研究数据教学模块 V1：第3章 从考古资料到可计算数据

编写组讨论稿，尚非审定教材正文。 本模块依据已核验的真实研究工作簿结构和公开论文资料编写，但不提供原始Excel、私有CSV、真实行级数据或未经授权的坐标。本页的数量来自审核报告，表格结构来自已审计工作簿；正式［阅读］评价须由教师提供经核查的原论文方法段或要求学生访问原始出版页面。

1. 本模块研究问题与边界

以Ran Zhang关于公元800—1900年西印度洋出土中国贸易陶瓷的研究为例，讨论考古材料如何被整理为关系表，以及“遗址”“陶瓷类别”“发现汇总记录”和“陶片数量”为什么不是同一个统计单位。

原研究：论文 DOI · Figshare数据 DOI · 数据审查档案。

本模块不进行贸易强度、海上航线或生产窑址的实证推断。原始记录复制和公开派生版仍待第三方权利、敏感性和编写组审核。不要求本科生使用R或Python。

2. 学习成果（5条）

  • C3-O1［核心］ 学生应能解释遗址、细分类、上位产品类型、Assemblage记录和陶片数各自的统计单位，并识别“896条记录=896片陶片”的错误。
  • C3-O2［核心］ 学生应能判断四个工作表之间的主键、外键和一对多关系，指出为何Site ID–Class ID不能充当Assemblage的唯一标识。
  • C3-O3［核心］ 学生应能核查结构性缺失、字段缺失和重复组合的区别，解释为什么7组相同遗址—类别组合不能自动删除。
  • C3-O4［阅读］ 学生应能比较原论文某项数量陈述与审计工作簿的对应单位，辨认“12/15”与“869/896”异文，并提出需要核查的版本与记录定义问题，而不推测其原因。
  • C3-O5［阅读］ 学生应能判断一组遗址分布／陶片计数是否足以支持贸易路线或交易量的解释，并说明保存、调查和研究汇编偏差可能怎样影响推论。

3. 已核验的资料与数据关系

表 记录层级 核验规模 关联原则
Part 1 – Sites 遗址 216行 Site No唯一
Part 2 – Classification 陶瓷细分类 55行；另有15种上位产品类型 Class ID唯一，Product Type为分类属性
Part 3 – Chinese Ceramic Finds 发现汇总记录 896行 Assemblage ID唯一；Site ID和Class ID引用上述两表
Part 4 – Aoristic Results 对896条汇总记录的年代权重计算 896条明细（另有说明／汇总内容） 与Finds按审核记录对应；不是另一批896个遗址或陶片

896条发现记录包含 31,729片陶片（Sherd Number合计）。不应将它们误称为896件完整器物、31,729次交易或31,729个独立测年事件。模型分配结果详见第11章真实数据模块。

为什么会出现“重复”？

审核中发现7组相同 (Site ID, Class ID) 组合，但每条都有不同的Assemblage ID：Kinolhas（6组）与Suakin（1组）。由于其记录来源、采样单位和潜在重复计数问题未获作者解释，教学中须保留原始14条相关记录，不能直接合并为7条。

Country 中的26种文本标签包含区域／属地名称（如Southern Africa），不是26个主权国家。原Sites表没有经纬度，不能直接绘制准确遗址点位。

教师配套： 原论文阅读定位与四项任务评分量规。请先核对全文可访问性及适用许可。

4. 必做综合评价（无代码）

材料包： 此页面的四表结构摘要；V1文件级核验记录、V2记录及异文审查、原研究的数据发布页。无需获得私有CSV。

T3-A：关系与统计单位审查卡（必做，约20分钟）

  1. 对216、55、15、896、31,729分别填写“统计对象”和“不能等同于什么”。（O1）
  2. 画出 Sites — Finds — Classification 的简化关联图，标出Site No、Class ID及Assemblage ID的用途；解释为什么Site ID–Class ID不是唯一键。（O2）
  3. 面对7组重复组合，指出“保留原始行”“标记待核”“直接删掉重复”三种处理中的合适顺序，并说明不足的证据。（O3）
  4. 给出“可说明的观察”“不能据此证明的历史解释”各一例，联系调查偏差与汇编偏差。（O5）

T3-B：真实论文方法审查（必做［阅读］证据，约10–15分钟）

阅读教师核验并合法选取的论文方法段（或通过原始论文页面阅读），指出12/15与869/896的叙述差异属于哪些统计单位、如何向作者求证、以及为什么不能仅凭异文自动修改Excel表。（O4）

5分钟随堂问答： 一条Assemblage记录与一片陶片有何不同？“没有经纬度”与“没有遗址名称”是否相同？用于复核O1、O3、O5。

5. 学习成果 × 评价证据矩阵

成果 对应教材主题 必做评价证据 判定学生达到要求的观察指标
C3-O1［核心］ 3.1、3.2、3.4 T3-A第1题＋短问 五类统计单位区分正确，不混淆陶片与汇总记录
C3-O2［核心］ 3.4、3.8 T3-A第2题 识别主键、外键、一对多关系，未把Site×Class误判唯一键
C3-O3［核心］ 3.5、3.8 T3-A第3题＋短问 能说明7组组合不等于数据错误，要求保留并标注待核
C3-O4［阅读］ 3.1、3.8 T3-B原论文审查 区分论文表述与工作簿计数、提出合理核验问题
C3-O5［阅读］ 3.6、3.7、4章先修 T3-A第4题＋短问 能指出保存/调查偏差和计数—贸易推论的界限

覆盖规则： 五项成果均由可收集的必做证据检验；O4的最终阅读要求必须使用真实论文，不得只读模拟材料。教师应保存题目、所用论文版本、评价记录和简短评分说明。

6. 答案判定原则与常见错误（非学生标准答案）

不以学生重复某个单一历史解释为评分标准，而以其是否能够区分数据记录与证据推论、核对实际定义、提出有依据的待核问题为准。以下处理应判为问题：未经说明删掉重复行；把Country标签直接转化为主权国家数；未经来源核验补充遗址坐标；把31,729片陶片换算成交易数量。

7. 继续深入与开放状态

此模块可先作为研究设计与证据评价教学，不需要开放真实数据文件。正式数据实操版须待许可、敏感性审查、重复记录定义和编写组批准后另行发布；原始Excel及所有私有转换文件仍只保存在受控环境。

来源等级提示： 数字与关联一致性来自2026-10-14已通过的文件级与独立CSV转换核验（51 PASS / 0 FAIL）；这些核验不等于作者已经确认7组重复记录的性质，也不等于贸易网络解释已得到独立证实。
