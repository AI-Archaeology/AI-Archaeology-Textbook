真实数据教学模块 V1.1：四项必做任务逐维评分量规

教师讨论稿。 保留10条学习成果和四项任务结构。每项任务四个维度、每维0–3分、总计12分。以下为判分锚点设计，不代表已经完成教师试评分、评分者间信度评估或真实学生试测。模拟计算题均非原始考古数据。

通用评分规则

3分：判断准确、证据和解释充分；2分：核心正确但有小遗漏；1分：部分正确但关键解释不足；0分：核心判断错误或无有效作答。每一维独立评分，同一错误不要在无关维度重复扣分。未作答记0。不能只因为答案简短而自动扣分，需查看该维是否满足要求。

1. T3-A：关系与记录质量（12分）

维度及学习成果 3分 2分 1分 0分
A1 统计单位 C3-O1 216/55/15/896/31,729各自单位全对，举两例说明分母不能互换 五个单位至多一处小遗漏，解释一种不能互换的关系 辨认部分单位，但混淆类别、记录或陶片 把Assemblage当陶片或陶片数当交易次数
A2 主键关联 C3-O2 指出三表主键、两个外键、一对多关系，说明Site×Class不唯一 主外键和非唯一性正确，关系方向少一处说明 只识别部分键或不能解释非唯一性 把Site×Class当唯一键据此错误关联或去重
A3 重复与缺失 C3-O3 7组重复保留待核；区分虚构0、NA和Not applicable，检查测量合理性及平均值分母 重复处理与三种状态大体正确，少一项核查说明 仅能正确处理重复或缺失中的一部分 擅删不同ID或把NA/不适用当0参与计算
A4 推论边界 C3-O5 不把陶片数等同贸易量/航线，解释两种具体偏差的影响 区分统计与历史推论，解释至少一种偏差 只泛称偏差存在，不说明机制 直接把陶片数当交易事件或完全无证据限定

2. T3-B：真实论文阅读与数字异文（12分）

维度及学习成果 3分 2分 1分 0分
B1 原文定位 C3-O4 定位Abstract、Introduction、Figure 2中的至少两处具体且可复核陈述 两处定位基本正确但一处不够精确 只有一处具体原文定位 无原文定位或编造引文
B2 数量单位 C3-O1/O4 明确12/15是产品类型异文、869/896是Assemblage异文，均非陶片数 两组及单位正确但缺简要解释 只识别一组或混淆一个单位 将四数说成同一单位
B3 版本核验 C3-O4 区分论文文字与附表，提出核版本或定义的具体途径，不推测原因 提出作者或版本核验但缺具体路径 只说可能是笔误而未拟核验 直接按猜测更改源数据
B4 证据局限 C3-O5 说明一种文献/调查/保存偏差机制及一项需要另证的贸易推论 偏差与贸易局限均提及但联系不足 仅泛称研究有限制 以数字异文直接推导贸易历史真伪

D1 方法定位 C11-O1/O4 定位Methodology并解释区间、均匀分配及百年箱的假设 定位准确且理解均匀分配，缺一细节 仅笼统说明年代不确定性或缺具体位置 声称逐片直接测年或无有效原文证据

D4 推论边界 C11-O4/O5 区分权重与历史趋势，说明非贝叶斯、非自动AI 历史推论边界准确，但少一方法区别 仅说模型有局限未解释 把Aoristic、贝叶斯和AI等同并当历史证明

达标与主证据

  • T3-A：建议总分≥8，A1、A2均≥2；另外单独检查A3≥2，确认C3-O3中重复与缺失两方面都已形成证据。
  • T3-B：建议总分≥8且B1≥2。若学生无法合法获得指定真实论文材料，暂不对阅读能力评分，不应直接记0。
  • T11-A：建议总分≥8，C1、C2均≥2；另检查C3≥2，确认C11-O3有分箱应用的实际证据。
  • T11-B：建议总分≥8且D1≥2；若原文图表不可访问，不得要求学生猜测图中真实趋势。

上述阈值沿用V1的一般建议，A3与C3的成果诊断是新增建议，尚待教师审定。总分和各学习成果的达标判断分别记录，不将T3-B/T11-B里的复测证据重复计入同一成果的总分。

教师试评分流程

  1. 两名教师先对完整且经许可使用的匿名答案独立评分，保存每维原始分数，再讨论差值≥2或是否跨越建议阈值的情况。
  2. 逐项核查学生是否获得必要资料。虚构学生答案摘要仅供理解边界，不能用来宣称实际信度。
  3. 记录任务用时、学术概念困难与反馈。预留T3-A 25–35分钟、T3-B 20–30分钟、T11-A 25–35分钟、T11-B 25–35分钟，仅是排程建议、不是实测时间。
  4. 来源、数字异文、7组重复组合含义与版权敏感性问题仍待原研究和编写组进一步核验；不公开私有Excel或CSV。
