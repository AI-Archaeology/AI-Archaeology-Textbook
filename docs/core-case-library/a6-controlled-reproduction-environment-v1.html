A6 受控复现环境 V1：隔离安装与数据编码冒烟测试

实施准备稿，非已运行的复现报告。 本阶段只建立独立Python环境、核对已验证的官方CSV输入及一个完全虚构的类别编码/缺失值最小测试。不安装或修改作者2014年源代码，不执行EM，不发表新的聚类结果。

一、已知事实与测试目标

  • 原研究：Gansell et al. 2014，Journal of Archaeological Science 44:194–205，DOI。
  • 固定ANEIC代码：core 43a394f3a2409f2918d38f9d3cfc6dd5472970c1；scripts c45445a0e090853c6eb544bffe8042557e4db440。
  • 既有A6输入验收：官方CSV的Git Blob与本地文件一致，162行、34列，除Key与Site以外32个候选特征，1,931个空白单元格；12/12模型输入检查通过。
  • 静态兼容性审查已经发现Python 2 print、pandas历史分类API、.ix及np.object等障碍；13项静态检查通过不意味着可运行原模型。

本轮新脚本：独立环境和数据编码烟雾测试。采用Python标准库读取真实CSV的结构，现代NumPy/pandas仅验证虚构小表的编码及缺失语义。

二、隔离环境策略

位置： downloads/private-workflow/a6-reproduction/.venv，避免触及当前Positron解释器和R/Quarto项目的包。

  1. 使用Positron Terminal中的python3创建独立venv；不要将该环境设置为整个教材项目的默认解释器。
  2. 先在独立venv执行python -m pip install numpy pandas，记录实际安装版本、平台与Python版本；这不是已经验证、可以直接复现2014年模型的锁定依赖文件。
  3. 使用独立环境中的Python运行只读冒烟测试，不直接导入aneic包。
  4. 若测试失败，记录原始报错并停止。不得通过修改原始数据、全局降级Python或把缺失值填0来消除错误。
  5. 只有冒烟测试通过，才能进入后续独立且可追踪的兼容补丁实验；补丁放在私有工作副本，保留原仓库git diff，并附行为等价性测试。

三、在Positron实际运行

以下命令均从教材项目根目录执行。官方CSV继续保存在Git忽略的本地目录，不要用git add -f强制提交。

python3 -m venv downloads/private-workflow/a6-reproduction/.venv

downloads/private-workflow/a6-reproduction/.venv/bin/python -m pip install numpy pandas

downloads/private-workflow/a6-reproduction/.venv/bin/python \
  audit-tools/a6_environment_smoke_v1.py \
  downloads/official/levantine_corpus_gansell.csv

脚本逐项报告：虚拟环境隔离、官方CSV SHA-256、162×34行列、Key唯一、5个Site标签、1,931处特征缺失、12列数值可解析、虚构类别缺失保留和虚构数值缺失计算。

本轮尚未执行该脚本。 预计产生如下私有报告：

  • downloads/private-review/a6-ivories/A6_ENV_SMOKE_CHECKS_PRIVATE.csv
  • downloads/private-review/a6-ivories/A6_ENV_SMOKE_PRIVATE.json

通过之后，再记录一份仅在本地保存的环境依赖清单：

downloads/private-workflow/a6-reproduction/.venv/bin/python -m pip freeze \
  > downloads/private-review/a6-ivories/A6_ENV_PIP_FREEZE_PRIVATE.txt

请不要将冻结依赖清单视为已经证明2014年原算法可以运行。 需要下一阶段实际兼容补丁和数值回归测试之后，才考虑公开受审定的独立环境说明。
