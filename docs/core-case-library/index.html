AI考古学核心案例库：六例数据与教学准入审查 V1

编写组审查资源，非已批准的数据发行目录。 六例均发表于目标期刊并使用机器学习或深度学习；本页仅完成论文/仓库/数据发布页面的第一轮外部核验。尚未下载、核对checksum、运行代码或独立复现研究结论。真实性、可下载性、再分发权、敏感性和可复现性分别判断。与中国贸易陶瓷Real Data 01不同，后者并不是AI算法案例。

本次准入判定规则

状态 含义 允许的教学活动 尚不允许
A-：优先私有技术试验 特征数据和明确的语料许可证据已经定位，但尚未实际文件级核验 论文阅读、结构摘要、经独立编写的模拟练习；准备受控下载与校验 直接复制真实CSV到公开网站；宣称结果已复现
B+：论文声明与存储库可核 原论文明确公开数据与代码、仓库文件目录可见 论文评价、数据来源评估、预制模拟练习 未审查具体文件授权即托管或复现声明
B：论文与开放资料入口可核 部分数据、代码或下载文件清单存在，版权/具体结构/测试方案仍待审 文献评议、输出审查、来源链练习 整包复制、开放真实图像或铭文语料

状态是教学准入排程，不是学术排名。 所有六例仍为“真实数据公开再分发：未批准”。

共通的学生学习路径与评分证据

Level 1：论文证据审查（必做，无代码）。明确研究问题、原始观测单位、模型输入输出、传统比较基线、误差与推断边界。提交一页四栏证据表。

Level 2：经过审查的演示材料（必做，暂用自行虚构数据）。在尚未确认许可前，只使用显著标为虚构的混淆矩阵、缺失示例或残文，评估模型预测与考古证据之间的推论链。

Level 3：原始资料小型练习（选做、待准入）。先核验原仓库实际文件、版本/哈希、类别/ID、训练测试划分、再分发许可及遗址/文化资料敏感性；批准后才能构建有数据字典和出处的教学子集。

Level 4：研究复现（高级选做、尚未批准）。在软硬件环境、数据权限和评价协议审查后尝试运行原程序，不以“公开代码”替代复现成功证据。

A6进展更新： 已直接读取固定commit的官方CSV，记录其162行×34列、1,931个空白单元格，并核对语料与图像分别授权。详细结果见A6第二阶段文件初审；仍需在Positron执行独立R脚本核验本地SHA-256，不能称为聚类复现通过。

A6复现准备： 2014年算法与现代Python兼容性审查V1。已定位Python 2语法和旧pandas/NumPy接口，下一步只读检查固定仓库版本，不安装旧依赖。

A6受控复现准备： 独立Python环境与最小编码冒烟测试V1（未执行历史EM，不是数值复现）。

A6最小数学行为检查（新）： 完全虚构数据的EM数值基准V1。它不运行历史原算法，也不产出真实器物聚类结果。

A6原始模块局部核验候选： 私有兼容副本和独立虚构概率对照V1。这比自编演示算法更接近原研究，但尚未执行完整E/M步骤。

A6原作者E/M函数试验： E步与M步的私有兼容副本和虚构数值对照V1，测试准备尚待运行，不是历史聚类结果的复现。

A6完整EM短程测试准备： 原作者em()循环的私有compat-v3诊断V1。尚未在Positron执行，不代表真实象牙聚类已复现。

A6循环控制审查： EM收敛条件与返回状态一致性V1。本轮观察原作者私有兼容版的停止及输出语义，不使用真实器物数据。

A6历史与修正返回状态比较： 私有compat-v3和compat-v4的对照V1。仅用虚构数据，尚未在本地执行。

A6停止条件审查： 历史与候选停止判据、三个随机种子的虚构数据对照V1，尚未经本地实际运行。

A6真实数据小规模试验准入： 只读复现准备核验与HOLD决策V1。即使技术PASS也不自动授权真实数据训练。

文件核验与出版准入清单

A6专题已扩展： 论文与原始代码复现前审查以及第5章、6章、10章的三项无代码教学模块。模拟练习不构成模型结果复现。

下一步工作优先级

1. A6 Levantine ivories（特征表）：最适合先完成受控文件核验，并转成不需大型训练环境的无代码练习。

2. A1 Charcoal hearths（检测流程）：从Zenodo小型人工标注/瓦片元数据开始，避免下载大模型，优先设计误报、漏检、空间偏差及验证练习。

3. A4 Tusayan pottery（图像分类）：在确认855MB图像压缩包许可及图像—陶片对应关系后，设计类别标签分歧教学。

4. A5 Evron + A2 Ithaca + A3 Aeneas：分别开展光谱、古文字语料来源与许可、生成/检索模型的进一步独立核验。
