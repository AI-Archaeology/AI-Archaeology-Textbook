A6 Levantine Ivories：官方属性CSV初步文件审查 V1

状态：已直接读取官方固定commit的CSV并进行独立解析；本地下载、SHA-256与R脚本重跑仍待用户在Positron完成。 此页只包含汇总统计和核验指令；不再分发真实属性CSV或第三方器物图像。这些结果是数据结构审计，尚非聚类模型复现。

固定来源与版本

  • 论文：Gansell, van de Meent, Zairis & Wiggins (2014), Journal of Archaeological Science 44, 194–205。论文DOI。
  • 仓库：aneic/aneic-core，固定commit 43a394f3a2409f2918d38f9d3cfc6dd5472970c1（GitHub提交记录为2014-04-30）。
  • 官方数据路径：data/levantine_corpus_gansell.csv；该commit的Git Blob SHA-1：872b73195836fc8558f317b7be9fc9441aec30ad，GitHub API登记大小22,846字节。Blob SHA-1不是下载文件的SHA-256，不得混为一谈。
  • CSV固定版本原始链接。用于私有下载，不要添加到公开GitHub。
  • 官方语料许可：Amy Gansell ©2013，CC BY-SA 3.0 Unported。
  • 图像单独版权声明：涉及博物馆许可、作者绘图以及第三方艺术家的作品；不能以CSV许可替代图像许可。

官方CSV直接读取的首轮结构结果

核验项 当前观察结果 证据性质
CSV数据行数 162 固定版本原文CSV按RFC风格引号/逗号解析
字段数 34 表头与所有数据行均34列
主键候选 Key，162个非空且不重复 字段级结构核查；不证明每行是不同完整器物
Site 5种非空文本标签 Nimrud 126；ArslanTash 26；Khorsabad 7；SharifKhan 2；Nineveh 1
数值字段候选 第3–14列共12列 形态测量及比例变量；单位与可比性仍需论文核验
类别字段候选 第15–34列共20列 头发、装饰、面部属性等；含可能缺失/不适用值
空白单元格 1,931 全部162×34单元格中的空字符串；不表示已证明随机缺失
无空白字段 Key与Site两列 其余32列至少有一处空白
记录宽度 162/162行均34列 未发现列错位

重要限制： 这些数字来自对GitHub当前固定CSV文本的独立解析，尚未通过用户本地的SHA-256下载和R脚本复测。不能直接称其为“复现了2014年论文的统计结果”；特别需要核对作者是否在分析中进一步筛选样本或剔除高度缺失的器物。

缺失与变量质量要解决的具体问题

  1. 12列形态比例缺失程度不一；第3–14列中若无法形成可比较的距离，不应将空白直接置0。
  2. 20个类别属性混合了多种状态（yes/no、装饰类别、形态描述），必须核对每列可允许的水平及编码约定，不应不加区分地转换成整数尺度。
  3. 同一遗址标签下可能存在较多具有相似风格的器物；Site是考古出处的描述变量，而非训练中天然可信的风格标签。
  4. Key唯一只表示CSV记录标识符唯一，尚不能证明缺少来自同一器物的重复视图、版本变体等关系。
  5. 由数据属性自动聚类得到的组，不应未经独立证据便命名为制作作坊、族群或社会身份。

私有文件级复核程序

后续使用独立只读审核脚本，在Positron本地私有目录运行。脚本重新检查行列、键唯一、类别分布、缺失、数值字段类型，并计算本地文件SHA-256。仅在私有目录生成汇总报告；不会对数据进行填补、清洗或默默删除记录。

教学输出（当前无需开放真实数据）
