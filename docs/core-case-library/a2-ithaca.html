A2｜Ithaca / 古希腊铭文复原 — AI考古学核心案例准入档案 V1

状态：B：论文与模型工具链可查；语料再分发许可未核实。 本页是论文/存储库级的第一轮准入审查，尚未下载、校验或运行完整数据/模型；不构成可重复性已证实或再分发已经批准的声明。教学模块不直接托管真实数据或敏感坐标。

研究问题与方法

  • 论文：Assael et al. (2022), Nature 603, 280–283。DOI。
  • 考古学问题：模型补全损毁铭文并推断其来源地与年代时，专家如何核实候选文字与解释的不确定性？
  • AI方法：Transformer/深度神经网络，支持文本补全、地区与年代归属，强调专家协作。
  • 观测/分析单位：一条铭文文本及其出处/年代元数据；被遮挡的片段、候选字符与预测时间/地理位置；源库条目可能存在编纂修订。
  • 非AI比较基线：拓片/铭文释读、古文书学、平行文本比对、地层与年代学证据。

本科教学设计（不依赖私人或受限数据）

建议使用章节： 第8、11、18、22–23章；最终以已锁定25章教材大纲为准。

学生应能（候选学习成果）：

  1. A2-O1：能区分观察到的原文字母、缺损符号、模型候选和专家校订。
  2. A2-O2：能解释候选排名/注意力可视化不等于历史真实性。
  3. A2-O3：能提出按铭文、出处或文本族群分组核查的验证方式。

必做无代码评价（提议）： 使用教师自制且标为虚构的刻文残损练习和真实论文方法说明，对照两个候选复原并给出独立证据要求；不复制PHI大语料。

选做进阶（先通过文件/许可审核）： 在原平台访问与权限规则下运行官方演示示例，不要求下载或训练大型模型。

对学习证据的最低要求： 学生提交一页证据判别表或短评，至少包含研究资料单位、AI输出与原始观察的区别、传统比较基线、两种误差或偏差来源、对考古结论所需的独立核验。评分由后续专门量规处理，本档案不宣称已试评分。
