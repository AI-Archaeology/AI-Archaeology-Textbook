源码与真实数据的保存原则

实际器物CSV、私有兼容副本、各项模型输出和私有核验报告仍保存在本地downloads/中，不公开复制到教材网站。原作者语料许可证、程序许可证与第三方图片授权必须分别判断。

历史算法的修改副本仅用于对照实验。对于论文描述的33项与固定程序实际32项输入、真实数据Gaussian精度先验b的构造、训练策略和正式试运行授权，应保留未解决状态。不得把虚构数据的EM数值验证等同于真实象牙风格分组的复现。
