A6真实数据试运行协议定稿 V1：固定方案与准入边界

本协议是待批准的受控试验设计，不是已经执行的真实数据聚类。 技术文件可以完成核验，但在剩余学术问题解决且研究者明确批准前，PILOT AUTHORIZATION 始终为 HOLD。本阶段不运行原作者EM算法，也不输出任何对象级属性或聚类概率。

一、科学问题与实验性质

A6案例研究了使用混合数值与类别属性的概率聚类探索黎凡特象牙雕刻风格。经过原作者源码审查、现代Python兼容修补、虚构数据上的E/M验证、完整EM短程测试和历史停止控制的对照，我们已经具备描述一项可审核的真实数据小规模诊断试验所需的部分技术基础。

本轮要回答的是试验如何设计、如何记录、什么条件下才允许执行，不是“能否直接运行K=2至10完整搜索”。拟议的K=2、单一随机种子17、一次初始化和有限迭代仅用于资源受限的技术试运行，不用于宣称最佳簇数或重现2014年的正式统计结论。

三、先锁定模型政策，再决定运行

建议以私有 compat-v4 作为技术试运行主版本：维持原作者停止条件，在输出时对齐模型参数、成员概率和目标函数的计算状态。私有 compat-v5 只作为候选停止规则的敏感性对照，不得称为未经修改的历史版本。

若未来需要检验纯历史输出语义，必须另设清楚标注的compat-v3对照，不能将compat-v3、v4、v5结果混合后宣称完全复现作者实验。

参数 拟议受控首次试运行 与历史方法的关系
K 2 技术性测试值，不是簇数选择
随机种子 17 与原运行脚本seed=1不同，必须明示
初始化 1次 原脚本曾设100–500次重启，本次不复现
最大迭代设置 3 仅资源上限，具体E步次数以日志为准
高斯精度先验a 2.0 与所审查普通运行脚本配置一致
sigma 1.0（待确认进入b的公式） 尚未验证原b的构造、特征方差及单位
alpha与beta 暂拟None 必须和实际runner路径比对

关键HOLD： 此前虚构实验使用的常数b=2不得直接复制到真实数据。需先核实历史运行脚本如何从sigma、特征方差及a构造b，再证明新环境中计算方式一致。直到该点核实，不能批准拟合。

四、可执行的只读协议检查

本轮添加两份公开的研究工具源文件（不包含原始语料）：

  • 拟议协议配置（JSON）：明确固定来源、输入定义、实验版本、建议参数、需解决的准入限制及私有报告字段。
  • 只读准入检查脚本（Python）：在本地核对CSV SHA、文件结构、私有兼容副本的精确差异、原Git版本及环境元数据，不导入ANEIC，不执行EM，也不输出任何研究记录。

从教材项目根目录运行：

downloads/private-workflow/a6-reproduction/.venv/bin/python \
  audit-tools/a6_pilot_protocol_check_v1.py

预计私有报告输出：

downloads/private-review/a6-ivories/
  A6_PROTOCOL_FINALIZATION_CHECKS_PRIVATE.csv
  A6_PROTOCOL_FINALIZATION_PRIVATE.json

技术PASS只是“来源与协议约束无冲突”；不会修改配置中的authorization: HOLD，也不代表通过了统计学或伦理核准。

五、未来试运行的最小记录要求

在批准拟议试运行之前，必须预先规定精确输入CSV哈希、32项特征顺序和缺失位置、类别水平及编码、兼容补丁哈希、软件版本、先验参数推导、随机种子、K、初始化次数、目标函数轨迹、真实停止原因以及q/gamma/L返回状态一致性检查。任何对象级归属或概率必须仅在私有目录留存，不应进入公开教材网页、Git库或教学附件。

结果还必须区分计算成功、准则满足、学术上可与作者结果比较三个不同状态。单次K=2测试绝不能用来判断原作者K=2–10中的最优簇数。

六、正式准入条件（仍未满足）

  • 特征口径： 文中33项与固定程序32项差异需得到可追溯解释，或明确规定不影响技术试运行但禁止声称精确复现。
  • 输入和先验： 原程序CSV类型推断、one-hot类别顺序、缺失处理和由sigma及方差计算b的路径需独立核验。
  • 方法版本： 书面锁定主版和敏感性版，保留每种控制流程的修改清单。
  • 结果和比较： 提前固定输出模式、异常停止处理、与原论文可比性界限。
  • 数据与权益： CSV遵守CC BY-SA条款；第三方馆藏图片不得混入开放材料。
  • 明确许可： 在实际运行真实数据拟合前，由研究者做单独go/no-go决定。

结论： 本轮仅将A6第一次真实数据技术诊断推进到可审核的拟议协议阶段，不解除HOLD。
