- 许可：Figshare 页面标注 CC BY 4.0，仍需检查附件和第三方权利。
- 当前状态：**来源核对通过；原始附件下载、字段核对、敏感性与再分发审核未完成。**
- 网站评审页：`real-data-candidate-chinese-ceramics.qmd`
