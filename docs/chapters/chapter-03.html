3  从考古资料到可计算数据

教学示范页（非定稿章节）。下文使用完全虚构的数据说明如何记录、整理和评价考古资料，不提供真实遗址研究结论。

3.1 本章问题

一件陶片怎样成为数据表中的一行？考古学家把器物描述转换为可计算字段时，保留了什么，又可能丢失哪些信息？

3.2 学习成果

完成本示例后，学生应能：

  1. 解释考古实物、记录、观测单位和数据字段之间的区别。
  2. 判断类别变量、数值变量与二元编码的意义及适用条件。
  3. 核查空白、未记录和零值是否被混为一谈。
  4. 比较按碎片记录与按遗迹／器物组合汇总的不同研究含义。
  5. 说明为何数据分组本身并不能证明年代、工艺或社会差异。

3.3 教学数据：虚构陶片属性表

本章采用 教学模拟陶片属性数据 01。表中有18条虚构陶片记录、8个字段，所有记录均非真实考古资料。

字段 观测内容 需要注意
artifact_id 陶片标识符 标识符不是数值测量
context_id 模拟记录单位 不是实际遗址、地点或年代
fragment_part 口沿、腹片或底部 分类标准需保持一致
fabric 胎质记录 原始观察可能存在主观差异
surface_treatment 表面特征 “未记录”不是器物类型
rim_diameter_cm 口沿直径估计（cm） 非口沿留空，不等于0
coarse_inclusion_flag 粗颗粒夹杂记录（0/1） 0并非“证明不存在”
surface_unrecorded_flag 表面记录缺失标志（0/1） 用于数据质量审查

3.4 资料变为数据：五个关键判断

3.4.1 1. 一行代表什么？

在这张表中，一行是一条陶片记录，而不是一件完整器物，也不是一个遗址。同一记录单位可能包含多条记录。把碎片数量当作完整器物数量会产生错误结论。

3.4.2 2. 一列代表什么？

部位与胎质是类别变量；口沿直径是有单位的数值变量；0/1 是编码，含义取决于数据字典。编号字段不能拿来计算平均数。

3.4.3 3. 为什么有空白？

只有口沿碎片才适合记录口沿直径；其他部位的空白是结构性缺失。某条“未记录”表示观察记录欠缺，不能当作素面或任何真实表面类型。

3.4.4 4. 为什么需要来源和版本？

没有出处、编码规则和质量说明的数据表，别人无法判断它是否适合比较，更无法复核研究。真实考古数据还须注明抽样方式、保存偏差与使用许可。

3.4.5 5. 从表格能推断什么？

这份教学表只能支持关于数据结构、记录质量和分析流程的判断。任何关于真实器物类型、文化、年代、生产组织或交换的结论都超出了证据。

3.5 必做评价（无需编程）

材料：陶片表格和变量字典。

  1. 写出本数据的观测单位与两种不同类型的变量。
  2. 解释非口沿样本的 rim_diameter_cm 为空白与填为0有何不同。
  3. 说明将“未记录”当作一种真实表面类型会造成什么问题。
  4. 指出若希望判断两组陶片是否属于不同年代，还必须收集哪些独立证据。

评价覆盖： 成果1–3、5；成果4通过课堂短问“按碎片和按记录单位汇总，分母有何变化？”另行检验。基础评价不以运行软件为前提。

3.6 动手试试（选做）

用 Excel、LibreOffice、R 或 Python 任一工具打开 CSV；绘制碎片部位的频数图，并记录每个字段的缺失情况。务必在输出写明“教学模拟数据”。不得将可视化结果解释成真实遗址发现。

3.7 何时用、何时不用

结构化表格适合整理重复观察、进行一致性核查和简单统计；对出土环境、器形整体、非标准化观察及文化解释等复杂问题，字段化会损失语境。必要时应返回原始记录、照片和实物，不应仅依赖表格或模型结果。

3.8 同一问题的其他解法

传统手工登记册、电子表格、关系数据库、规则式字段抽取和AI辅助信息提取各有前提。是否使用AI应根据资料规模、记录一致性、来源可追溯性、核查成本与误用风险判断。

3.9 继续深入

先理解数据字典、测量尺度与缺失机制，再进入第4章的偏差与不确定性、第5–8章的方法基础。真实研究案例和分层阅读文献仍待编写组核验补充。
